# Roadmap

Nothing here has been agreed with the user yet. These are the natural next steps from the chat.
Confirm the first decision with them before building.

## 0. Decide where it lives (ask first)
- **A. Stay a claude.ai artifact**: no backend, Claude features included; but no mic or live audio, and
  dictation only in Chrome or the desktop app.
- **B. Hosted web app** (for example Next.js on Vercel, with Supabase for history): real microphone, live
  prosody, server-side speech-to-text, Anthropic API backend, accounts. More work, plus API costs.

## 1. Quick wins (either route)
- [ ] Test with the user's real recording in a real browser; compare against the harness numbers.
- [ ] Confirm whether dictation handles non-English languages; if not, label those options "listen and mark-up only".
- [ ] Compare the user's pitch line with a model reading (for example a pitch line of the TTS reading, where possible).
- [ ] Mark the paragraph a live score belongs to, and keep the best score per paragraph.
- [ ] Practise one phrase at a time (shorter target than a paragraph).
- [ ] Minimal-pair drills (ship/sheep, think/sink, full/fool) generated by Claude for the learner's native language.
- [ ] Export or Copy button for the marked-up script.

## 2. Better evaluation
- [ ] Phoneme-level scoring (route B): forced alignment (for example Montreal Forced Aligner, or wav2vec2
      phoneme CTC) to check individual sounds: R, TH, H, vowel length, flapped T.
- [ ] Stress detection: compare the loudness, length and pitch of the expected stressed syllable with its neighbours.
- [ ] Per-phrase falling/rising check against the mark-up's expected tone.

## 3. Learning method content
- [ ] A short "How natural speech works" lesson: stress timing, reduction, linking, thought groups,
      intonation, with audio examples.
- [ ] A progress chart over time (rate, pitch range, % understood).

## Known limitations to keep in mind
- The word score measures intelligibility through a recogniser that autocorrects; it is not a phoneme score.
- The pause count during live dictation is approximate (gaps between dictation events).
- The syllable counter is energy-based and can drift ±10% from a true count.
- Native ranges are rough conversational English norms; other languages differ.
